# 概念速查

这份速查与实验室里的 5 个模块一一对应。括号中注明了对应的模块和预设，可以直接到实验室里看效果。

## 1. 法线与切线空间（模块 01）

- **法线 N**：垂直于表面的单位向量。光照计算几乎都从 `N·L` 开始，L 是指向光源的单位向量。
- **顶点法线与平滑**：
  - 顶点法线存在网格顶点上，三角形内部的法线由三个顶点插值得到。
  - 同一位置的顶点如果共享，法线会被平均，得到平滑着色。
  - 如果把顶点拆开，每个三角形各用自己的面法线，得到硬边。
  - 硬边物体（例如立方体）被强行平滑后，侧面会出现错误的渐变（预设「平直 vs 平滑着色」）。
- **坐标空间**：
  - 世界空间法线不随相机变化。
  - 视图空间法线以相机为参照。屏幕空间效果（SSAO、SSR）和 Godot 的 Normal Buffer 使用的都是视图空间法线。
- **切线空间 TBN**：
  - T（切线）沿 U 方向，B（副切线）沿 V 方向，N 是几何法线。
  - 法线贴图里存的 (x, y, z) 就是在这个局部坐标系里的方向。
  - 转换到视图或世界空间：`n = T*x + B*y + N*z`。
  - Godot 的副切线计算方式是 `B = cross(N, T) * tangent.w`，其中 w 是手性（±1）。
- **法线贴图编码**：
  - 编码方式为 `rgb = xyz * 0.5 + 0.5`。
  - 不扰动的像素是 (0.5, 0.5, 1)，也就是常见的淡紫色。
  - Godot 在采样后会根据 xy 重建 z：`z = sqrt(1 - x² - y²)`。
- **OpenGL 与 DirectX 约定**：
  - 两种约定的区别在于绿通道（Y）的方向是否相反。Godot 使用 OpenGL 约定（Y+ 朝上）。
  - 用错约定的症状：凸起看起来像凹陷（预设「绿通道翻转」）。
- **色彩空间**：
  - 法线贴图是**数据**，不是颜色，必须按线性数据采样（`hint_normal`，或导入时选择 Normal Map）。
  - 如果被当成 sRGB 颜色做了 gamma 解码，所有法线都会整体朝 -X/-Y 偏（预设「错误色彩空间」）。
- **Bump mapping**：不需要切线，直接用高度图的屏幕空间导数（`dFdx` / `dFdy`）推导法线。

## 2. 光照模型（模块 02）

本节使用的符号：N 法线，L 指向光源，V 指向观察者，H = normalize(L + V)（半程向量），R = reflect(-L, N)。

| 模型 | 漫反射 | 高光 | 特点 |
| --- | --- | --- | --- |
| Lambert | `max(N·L, 0)` | 无 | 最基础的漫反射，背光面全黑 |
| Half-Lambert | `(N·L*0.5+0.5)²` | 无 | 背光面保留层次，非物理，常用于角色和卡通渲染 |
| Phong | Lambert | `pow(max(R·V,0), n)` | 经典模型，高光偏小偏尖 |
| Blinn-Phong | Lambert | `pow(max(N·H,0), n)` | 计算更便宜，更接近真实；要用大约 4 倍的 n 才能接近 Phong 的高光大小 |
| Toon | 把 N·L 量化成色阶 | 阈值硬切 | 风格化 |
| PBR (GGX) | Burley / Lambert | GGX + Schlick 菲涅尔 | 用 roughness/metallic 描述材质，能量守恒 |

- **能量守恒**：高光越集中，峰值应该越亮。Blinn-Phong 需要乘以 `(n+8)/8`，Phong 需要乘以 `(n+2)/2`。
- **菲涅尔**：视线越掠过表面，反射越强。Schlick 近似为 `F0 + (1-F0)(1-V·H)^5`。卡通渲染常用 `(1-N·V)^p` 做边缘光。
- **金属度**：
  - 金属没有漫反射，高光带有 albedo 的颜色。
  - 电介质（非金属）的高光是白色，F0 约为 4%。
- **Godot `light()` 函数的要点**：
  - 引擎为每盏灯调用一次 `light()`，结果累加到 `DIFFUSE_LIGHT` 和 `SPECULAR_LIGHT`。
  - `LIGHT_COLOR` 已经乘过 `energy * PI`，所以漫反射项要除以 PI。
  - `ATTENUATION` 同时包含距离衰减**和阴影**，所以背光面的 wrap 光照会被自身阴影抵消掉（模块 02 预设 ⑨）。

## 3. 光源与阴影（模块 03）

- **平行光（Directional）**：无限远光源，只有方向，不衰减。阴影使用 PSSM 级联。
- **点光（Omni）**：range 内按 attenuation 曲线衰减，attenuation = 1 时接近平方反比。阴影使用 Cube（6 次渲染）或 Dual Paraboloid（2 次渲染）。
- **聚光（Spot）**：
  - `spot_angle` 是锥角，`spot_angle_attenuation` 控制光锥边缘的软硬。
  - `light_projector` 用于投射 cookie 图案。
- **面光（AreaLight3D，4.7 新增）**：
  - 矩形发光面，沿节点的 -Z 方向单面发光。
  - 光滑表面上的高光是一个矩形，软阴影比较自然。
  - `area_normalize_energy` 开启时，改变面积不会改变总亮度。
- **阴影贴图原理**：先从光源视角渲染一张深度图，着色时比较像素深度与深度图中记录的值。
  - `shadow_bias` 太小会出现**阴影痤疮**（条纹或摩尔纹）。
  - `shadow_bias` 太大会出现 **peter-panning**（阴影与物体分离，薄物体的阴影甚至会消失）。
  - `shadow_normal_bias` 沿法线方向偏移，对掠射角更有效。
- **PSSM 级联**：
  - 近处的级联覆盖范围小、精度高；`split_1/2/3` 是各级边界占 `max_distance` 的比例。
  - `blend_splits` 用来消除相邻级联之间的接缝。
  - `max_distance` 越短，近处阴影越清晰，但远处没有阴影。
- **软阴影**：
  - PCF 过滤：由 `soft_shadow_filter_quality` 和 `shadow_blur` 控制，整个阴影统一模糊。
  - PCSS：由 `light_angular_distance`（平行光）或 `light_size`（点光、聚光）控制，离遮挡物越远阴影越模糊，接近真实的“接触硬化”。
- **色温**：1900K 烛光 → 3000K 钨丝灯 → 5500K 正午阳光 → 6500K 阴天 → 10000K 以上为天空蓝光。Godot 自带的 `light_temperature` 需要开启物理灯光单位才生效。

## 4. 间接光与环境（模块 04）

| 方案 | 实时性 | 适用场景 | 主要问题 |
| --- | --- | --- | --- |
| SDFGI | 实时 | 大型开放场景 | 墙比体素薄时会漏光，需要几帧收敛 |
| VoxelGI | 需要烘焙（可在运行时进行） | 室内、中小范围 | 只覆盖一个盒子范围，烘焙较慢 |
| LightmapGI | 只能在编辑器离线烘焙 | 静态场景，追求最高质量 | 不支持动态光，需要 UV2 |
| SSIL | 实时，屏幕空间 | 补充近距离的一次反弹 | 屏幕外的物体不参与 |
| ReflectionProbe | 一次性或每帧更新 | 局部反射和环境光 | 盒体投影只对盒状空间准确 |
| SSR | 实时，屏幕空间 | 地板、水面反射 | 只能反射屏幕上可见的内容 |
| SSAO | 实时，屏幕空间 | 接触阴影、角落变暗 | 只压暗环境光（除非设置 `ssao_light_affect`） |

- **环境光**：
  - 来源可以是 Sky、Color 或 Background。
  - Sky 模式下环境光来自天空的卷积，上下左右方向的颜色不同。
  - **坑**：来源为 Sky 且 `sky_contribution = 1` 时，`ambient_light_energy` 不起作用。
- **反射**：没有反射探针、也没有 SSR 时，光滑物体只能反射天空。

## 5. HDR、色调映射与后处理（模块 04、05）

- 光照计算在 **线性 HDR** 空间进行，亮度可以远大于 1。屏幕只能显示 0~1，所以需要**色调映射**来压缩：
  - Linear：直接截断，过曝区域变成纯色块。
  - Reinhard：简单的压缩曲线。
  - Filmic、ACES：电影风格的 S 曲线，ACES 对比更强、颜色更饱和。
  - AgX：高光向白色自然过渡，饱和色不容易“断层”。
- **曝光**在色调映射之前起作用：`tonemap_exposure` 乘以 `CameraAttributes.exposure_multiplier`；自动曝光会根据场景亮度动态调整。
- **大致处理顺序**：场景着色 → SSR/SSAO/SSIL → 雾、体积雾 → 辉光（取 HDR 中超过阈值的像素）→ 曝光与色调映射 → 调色（亮度/对比度/饱和度/LUT）→ 抗锯齿 → 自定义 CanvasLayer 后处理（读取已经色调映射过的 sRGB 画面）。
- **LUT**：1D 渐变只能按通道分别改曲线；3D LUT 可以把任意颜色映射成任意颜色（预设 Teal & Orange）。
- **线性与 sRGB**：
  - 颜色贴图是 sRGB 编码的，引擎采样时会转换成线性值。
  - 数据贴图（法线、粗糙度、高度）必须保持线性。
  - 屏幕输出前会再从线性转换回 sRGB，所以数值 0.5 在屏幕上看起来约为 73% 亮度。实验室中的调试视图已经做了反向修正。

## 6. 氛围配方（模块 05）

一个氛围通常由下面这些层组合而成：

| 层 | 作用 |
| --- | --- |
| 主光 | 决定方向、时间和情绪：色温、仰角、软硬 |
| 补光 / 天空环境光 | 决定暗部的亮度和色相，通常与主光形成冷暖对比 |
| 轮廓光 | 从背后勾出物体边缘，把主体从背景中分离出来 |
| 实用光源 | 画面中可见的灯具，是夜景的主体 |
| 大气 | 雾、体积雾、大气透视，提供纵深感和光束 |
| 后处理 | 色调映射、辉光、调色、暗角、颗粒，起“滤镜”作用 |

经验法则：

- **白天**：主光暖、环境冷，阴影偏蓝。
- **夜晚**：环境冷，局部光源暖。
- **阴天**：几乎没有方向光，物体的立体感主要靠 AO 维持。
- **恐怖氛围**：信息越少越好，光源不稳定（闪烁），低饱和度，加强暗角。
